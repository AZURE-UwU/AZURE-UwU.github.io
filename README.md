# AZURE-UwU.github.io

Bowen 的个人主页与技术博客，使用纯静态 HTML、CSS 和 JavaScript 构建。

## 页面

- `index.html`：个人主页
- `blog.html`：文章搜索与分类筛选
- `projects.html`：项目列表
- `about.html`：个人介绍
- `posts/`：独立文章页

## 本地预览

```powershell
python -m http.server 4173
```

访问 `http://localhost:4173/`。

## GitHub Pages

仓库名应为 `AZURE-UwU.github.io`，从主分支根目录直接发布。
