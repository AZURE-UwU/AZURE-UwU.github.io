DESKTOP / RUNTIME · 2026-11-09

Electron、WebView
与“浏览器系统”

网页技术正在成为系统里的 UI 层，但这不等于整个 Windows 变成了一颗浏览器。

Electron 用 Chromium 渲染界面，用 Node.js 连接文件和进程。它让一套 Web 技术可以发布成 Windows、macOS 和 Linux 桌面程序。

Electron 不是 Chrome

Chrome 是带地址栏、账号和通用浏览能力的完整产品。Electron 是开发框架，成品只在需要时提供窗口、菜单和系统能力。

Chromium网页渲染内核
ElectronChromium + Node + 桌面外壳
WebView2系统共享的 Edge 网页运行时

为什么到处都能看到它

聊天、设置页、文档编辑器和控制面板都适合用组件化 Web UI 实现。跨平台、热更新和前端生态带来的效率，往往比节省几十 MB 内存更重要。

代价是应用更大、进程更多，也需要更严格地处理渲染进程隔离、CSP 和原生桥接。

Windows 也不是一个巨大网页

任务栏、窗口管理和大多数 Shell 逻辑仍是原生组件。搜索、商店和小组件等内容区域会嵌入 WebView2，但内核、驱动和服务仍在下面。

局部使用网页渲染，不等于整个操作系统只有浏览器。

Codex 也是混合结构

桌面窗口使用 Electron 和 Web 前端，核心执行引擎则是独立 Rust app-server。界面和执行边界分开，才能既获得 Web UI 效率，又保留本地系统能力。
